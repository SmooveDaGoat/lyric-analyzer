# Lyric Analyzer

A lightweight, browser‑based tool that analyzes song lyrics for structure, rhyme patterns, and flow.  
Built to help artists, writers, and producers break down their lyrics visually and improve their craft.

---

## 🔥 Features
- Rhyme pattern detection  
- Line‑by‑line lyric breakdown  
- Clean HTML interface  
- Fast, simple, and mobile‑friendly  
- No backend required — runs entirely in the browser

---

## 📂 Project Structure
- `lyric-analyzer.html` — main interface and logic

More files will be added as the project grows.

---

## 🚀 Getting Started

### **Open the analyzer**
Simply open `lyric-analyzer.html` in any browser.

### **Usage**
1. Paste your lyrics into the input box  
2. Run the analyzer  
3. View rhyme patterns, structure, and breakdowns
